# Light House Agency - Sitio Web Oficial

Sitio web corporativo de **Light House Agency**, agencia de marketing digital en Guatemala.

## 🚀 Servicios

- Pauta Digital (Meta Ads)
- Creación de Contenido Publicitario
- Community Management
- Manejo de Inversión en Ads
- Análisis y Reportes
- Desarrollo de Páginas Web

## 🛠️ Tecnologías

- HTML5
- CSS3 (Bootstrap 5.3.2)
- JavaScript (Vanilla + GSAP)
- Google Fonts (Montserrat, Poppins)
- Font Awesome 6.5.1

## 📦 Estructura

```
alliedis-main/
├── index.html          # Página de inicio
├── services.html       # Página de servicios
├── css/
│   ├── style.css       # Estilos principales
│   └── services.css    # Estilos de servicios
├── js/
│   └── main.js         # Lógica y animaciones
└── img/                # Imágenes y assets
```
